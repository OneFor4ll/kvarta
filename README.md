# Кварта — кофейная обжарка в Минске

Сайт небольшой обжарочной компании «Кварта», которая предлагает свежую обжарку кофе, дрип-пакеты и подписку на кофе.

**Сайт:** [https://kvarta-zeta.vercel.app](https://kvarta-zeta.vercel.app)

## Функциональность

- Каталог кофе с описаниями и ценами.
- Информация о компании, доставке и самовывозе.
- Форма заявок с валидацией данных.
- Сохранение заявок в Neon PostgreSQL.
- Защита от повторной отправки заявок в течение 10 минут.
- Telegram-уведомления о новых заявках.

## Запуск проекта

Требуется установленный Node.js.

1. Установить зависимости:

   ```bash
   npm install
   ```

2. Создать файл `.env.local` в корне проекта и указать необходимые переменные окружения для базы данных и Telegram.

3. Запустить проект:

   ```bash
   npm run dev
   ```

4. Открыть [http://localhost:3000](http://localhost:3000).

## Использованные технологии

Next.js, React, TypeScript, PostgreSQL (Neon), Zod, libphonenumber-js, Telegram Bot API и Vercel.


## Что делал сам и что помогал делать ИИ

Во время разработки я самостоятельно анализировал код, проверял логику его работы и вносил исправления, если замечал ошибки или неудачные решения. Например, иногда ИИ предлагал написать весь код лендинга в одном файле без чёткого разделения на компоненты и модули. Я попросил разделить код по отдельным файлам, чтобы проект было проще поддерживать, исправлять и понимать другим разработчикам.

ИИ также не всегда давал достаточно точные или понятные объяснения. Например, при настройке Telegram-бота мне пришлось самостоятельно изучить процесс его создания и подключения, поскольку раньше у меня не было такого опыта. Я также самостоятельно тестировал сайт с помощью Lighthouse и работал над улучшением его производительности и оптимизации. При этом ИИ значительно ускорил разработку, помогая с повторяющимися задачами, написанием кода и созданием структуры базы данных.

## Ошибки ИИ и их обнаружение

В процессе разработки возникла ошибка при создании изображения Open Graph: Next.js требовал явно указывать CSS-свойство display для элементов с несколькими дочерними элементами. Я обнаружил проблему по сообщению об ошибке в терминале, после чего исправил код и проверил результат. При настройке Telegram-уведомлений также пришлось дополнительно разбираться с созданием бота, получением токена и Chat ID, настройкой переменных окружения и подключением уведомлений к API формы. Этот опыт показал, что предложенный ИИ код необходимо проверять и тестировать, а не использовать без понимания его логики.

## Что можно улучшить

Я бы добавил на сайт страницу с отзывами и рейтингами, где покупатели могли бы оценивать кофе и делиться своим мнением. Также я бы реализовал систему управления складскими остатками с отдельной таблицей в базе данных, чтобы сотрудники могли контролировать количество товаров, а покупатели видели, что доступно для заказа.

Ещё я бы добавил регистрацию и авторизацию с разделением ролей на покупателя, продавца и администратора. Покупатели могли бы сохранять товары в избранное, получать персональные рекомендации и подписываться на уведомления о появлении отсутствующих товаров. Продавцы могли бы управлять остатками, обрабатывать заказы и просматривать необходимые контактные данные покупателей. Администратор получил бы возможность добавлять, редактировать и удалять товары, а также управлять пользователями и продавцами.

Кроме того, я бы интегрировал систему онлайн-оплаты и добавил историю заказов, чтобы покупатели могли отслеживать свои покупки, а сотрудники — контролировать выполнение заказов. Для реализации этих функций потребовалось бы расширить структуру базы данных и уделить дополнительное внимание безопасности пользовательских данных, разграничению прав доступа и удобству интерфейса.
